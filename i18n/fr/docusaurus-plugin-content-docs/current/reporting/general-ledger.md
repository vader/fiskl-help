Ce guide explique comment utiliser le rapport du Grand Livre pour visualiser et analyser toutes les transactions financières de votre organisation avec des capacités puissantes de regroupement et de multi-devises.

## Qu'est-ce que le rapport du Grand Livre ?

Le rapport du Grand Livre fournit une vue complète de toutes les transactions financières au sein de votre organisation. Ce rapport est particulièrement utile pour les entreprises gérant plusieurs devises, offrant des informations détaillées avec une analyse flexible des transactions selon différentes dimensions.

<details>
<summary>Pourquoi le rapport du Grand Livre est-il important ?</summary>

Le rapport du Grand Livre est essentiel car il :

- Offre une vue détaillée de toutes les transactions avec des options de regroupement flexibles
- Fournit un support multi-devises à un niveau de détail sans précédent
- Aide à suivre et analyser les transactions selon différentes dimensions comme les comptes, les types et les dates
- Permet une analyse financière approfondie et un rapprochement

</details>

## Fonctionnalités principales

Le rapport du Grand Livre comprend des fonctionnalités puissantes pour une analyse financière complète :

- **Vues multi-devises** : Visualisez les montants en devise d'origine, la devise du compte du grand livre et la devise de base comptable
- **Ventilation détaillée des transactions** : Consultez le montant brut, le montant net et le montant de taxe pour chaque transaction dans leurs devises respectives
- **Informations sur les taux de change** : Suivez les taux de change pour un suivi facile des conversions de devises
- **Options de regroupement flexibles** : Regroupez les transactions par Compte du Grand Livre, Type de Transaction, Date, Année, Trimestre ou Mois

## Comment générer un rapport du Grand Livre

Avant de commencer, assurez-vous d'avoir enregistré des transactions dans vos comptes pour la période que vous souhaitez analyser.

### Étapes

1. **Accédez à la section des rapports**
   
   Dans le menu de gauche, cliquez sur **Comptabilité**, puis sélectionnez **Rapports**. Choisissez **Grand Livre** parmi les rapports disponibles.

2. **Sélectionnez vos comptes**
   
   Utilisez le sélecteur de comptes pour choisir tous les comptes ou des comptes spécifiques que vous souhaitez inclure dans le rapport.

3. **Définissez votre plage de dates**
   
   Choisissez la période pour laquelle vous souhaitez visualiser les transactions.

4. **Choisissez votre option de regroupement**
   
   Sélectionnez comment vous souhaitez organiser vos transactions : **Compte du Grand Livre**, **Type de Transaction**, **Date**, **Année**, **Trimestre** ou **Mois**.

5. **Personnalisez les paramètres du rapport**
   
   Ajustez les options suivantes pour adapter votre rapport :
   - Basculez entre les méthodes comptables de **Trésorerie** et de **Comptabilité d'engagement**
   - Basculez entre les vues **Résumé** et **Détaillée**
   - Activez l'option pour diviser les grands nombres par 1000 pour une lecture plus facile
   - Masquez les comptes vides sans transactions dans la période sélectionnée
   - Affichez ou masquez les soldes d'ouverture et de clôture pour chaque groupe

### Options de personnalisation

Vous pouvez adapter la vue du rapport avec ces options :

- **Sélection de comptes** : Visualisez tous les comptes ou concentrez-vous sur des comptes spécifiques
- **Plage de dates** : Définissez la période pour la visibilité des transactions
- **Option de regroupement** : Choisissez comment organiser les transactions pour l'analyse
- **Trésorerie vs. Comptabilité d'engagement** : Basculez entre les méthodes comptables
- **Bascule Résumé/Détail** : Sélectionnez entre une vue d'ensemble de haut niveau ou une vue détaillée des transactions
- **Visibilité des comptes vides** : Masquez les comptes sans activité dans la période sélectionnée
- **Affichage du solde** : Affichez ou masquez les soldes d'ouverture et de clôture pour chaque groupe

## Comprendre les colonnes du rapport

Le rapport du Grand Livre affiche des informations complètes pour chaque transaction sur plusieurs colonnes.

<details>
<summary>Voir une ventilation des colonnes du rapport</summary>

**Informations de base sur les transactions :**

- **Groupe** : La catégorie de regroupement, telle que Compte du Grand Livre, Type de Transaction ou Date
- **Date** : Quand la transaction s'est produite
- **Type** : Le type de transaction, tel que facture, dépense ou virement
- **Nom** : Le nom du client ou du fournisseur
- **Catégorie** : La catégorie de transaction attribuée
- **Description** : Brève description de la transaction

**Détails des montants :**

Le rapport affiche trois types de montants :
- **Montant brut** : Montant total de la transaction
- **Montant net** : Montant hors taxes
- **Montant de taxe** : Portion de taxe de la transaction

**Ventilation par devise :**

Chaque montant apparaît dans trois devises :
- **Devise d'origine** : La devise utilisée lors de l'enregistrement de la transaction
- **Devise du compte** : La devise du compte (pour les revenus et les dépenses, il s'agit de la devise de base)
- **Devise de base** : La devise comptable de base de votre entreprise

**Informations supplémentaires :**

- **Solde** : Solde courant du groupe lorsqu'il est activé
- **Taux de taxe** : Taux de taxe applicable pour la transaction
- **Taux de change** : Taux de change entre la devise de base et la devise du compte

</details>

## Personnaliser les colonnes du rapport

Vous pouvez personnaliser les colonnes qui apparaissent dans votre rapport pour vous concentrer sur les données les plus pertinentes pour vos besoins.

### Étapes pour personnaliser les colonnes

1. **Ouvrez le sélecteur de colonnes**
   
   Cliquez sur l'icône d'engrenage dans la vue du rapport.

2. **Sélectionnez vos colonnes**
   
   Dans le sélecteur de colonnes, ajoutez ou supprimez des colonnes selon vos besoins.

3. **Appliquez vos modifications**
   
   Votre sélection de colonnes sera appliquée à la vue du rapport et respectée lors de l'exportation du rapport.

<details>
<summary>Colonnes disponibles pour la personnalisation</summary>

- Numéro
- Type
- Client/Fournisseur
- Description
- Montant Brut (Devise d'origine)
- Montant Net (Devise d'origine)
- Montant de Taxe (Devise d'origine)
- Taux de change

</details>

:::tip[Astuce]
La personnalisation de vos colonnes peut considérablement rationaliser votre rapport, en particulier lors du traitement de scénarios multi-devises spécifiques ou lors de la concentration sur des détails de transaction particuliers.
:::

## Exporter votre rapport

Vous pouvez exporter votre rapport du Grand Livre pour une analyse plus approfondie ou pour le partager avec les parties prenantes.

### Options d'exportation

1. **Cliquez sur le bouton d'exportation**
   
   Situé en haut à droite de l'écran.

2. **Choisissez votre format**
   
   Sélectionnez entre le format **Google Sheets** ou **Excel**.

:::tip[Conseil d'analyse]
L'exportation vers une feuille de calcul permet une personnalisation et une analyse plus approfondies, particulièrement utile pour les scénarios multi-devises complexes et les examens financiers détaillés.
:::

## Meilleures pratiques

L'examen régulier de votre rapport du Grand Livre vous aide à :
- Maintenir des livres précis dans plusieurs devises
- Comprendre les impacts des devises sur vos finances
- Analyser les données financières selon diverses dimensions
- Obtenir des informations approfondies sur les activités financières de votre organisation
- Prendre des décisions commerciales éclairées basées sur des données de transaction complètes
