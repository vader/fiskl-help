Diese Seite erläutert, wie Sie Angebote in Fiskl nach der Erstellung verwalten — von der Bearbeitung und dem Versand bis zur Umwandlung in eine Rechnung oder zum Stornieren.

## Angebots-Vorschau

Wenn Sie ein Angebot auswählen, wird ein Vorschaubildschirm geöffnet. Die linke Seite zeigt, wie Ihr Kunde das Angebot sieht. Die rechte Seite zeigt Ihre Verwaltungsoptionen. Verwenden Sie diese Ansicht, um das Angebot vor einer Aktion zu überprüfen.

## Entwurfs-Angebote

Ein Entwurfs-Angebot ist für Ihren Kunden noch nicht sichtbar. Während sich ein Angebot im Entwurfsstatus befindet, können Sie:

- Alle Angebotdetails bearbeiten
- E-Mail-Versandeinstellungen konfigurieren
- Anhänge hinzufügen oder entfernen
- Die zugeordnete Marke ändern

Entwurfs-Angebote haben keinen Freigabelink verfügbar. Ihr Kunde kann das Angebot erst sehen, wenn Sie es versenden.

## Versendete Angebote

Nachdem Sie ein Angebot versenden, kennzeichnet Fiskl es als **Versendet** und macht es für Ihren Kunden sichtbar. Sie haben zwei Möglichkeiten, ein Angebot zu versenden:

- **Freigabelink generieren** — kennzeichnet das Angebot als Versendet und gibt Ihnen einen Link, den Sie über Ihren bevorzugten Kanal teilen können, z. B. eine Messaging-App oder E-Mail.
- **Per E-Mail versenden** — sendet das Angebot direkt an Ihren Kunden und kennzeichnet es automatisch als Versendet.

Nach dem Versand können Sie den Angebotsverlauf anzeigen, E-Mails verwalten und Anhänge hinzufügen oder entfernen.

## Bearbeitung eines Angebots

Sie können ein Angebot direkt nur dann bearbeiten, wenn es sich im Status **Entwurf** befindet. Um ein versendetes Angebot zu bearbeiten, müssen Sie es zunächst in den Entwurfsstatus zurückversetzen. Statusoptionen sind verfügbar, sobald das Angebot gespeichert wurde.

1. Öffnen Sie das Angebot aus Ihrer Angebotsliste
2. Wählen Sie den aktuellen Status
3. Wählen Sie **Entwurf** aus dem Dropdown
4. Nehmen Sie Ihre Änderungen vor
5. Wählen Sie **Speichern**

:::warning
Während sich ein Angebot im Entwurfsmodus befindet, funktionieren alle zuvor freigegebenen Links nicht. Der Link wird wieder aktiv, sobald sich das Angebot wieder im Status **Versendet** befindet.
:::

## Umwandlung eines Angebots in eine Rechnung

Wenn ein Kunde Ihr Angebot akzeptiert, können Sie es in eine Rechnung umwandeln.

1. Öffnen Sie das akzeptierte Angebot
2. Wählen Sie **Mehr**
3. Wählen Sie **In Rechnung umwandeln**

Fiskl erstellt eine neue Rechnung, die mit den Angebotdetails vorausgefüllt ist. Sie können die Rechnung vor dem Versand an Ihren Kunden überprüfen und bearbeiten.

## Stornierung eines Angebots

Wenn Sie ein Angebot stornieren müssen, beachten Sie Ihre Aufzeichnungen und alle Anforderungen in Ihrer Region. Fiskl bietet Ihnen drei Optionen.

### Option 1: Als abgelehnt kennzeichnen (empfohlen)

Ein Angebot als Abgelehnt zu kennzeichnen ist die beste Praktik für Stornierungen. Dies erhält Ihre Aufzeichnungen, ohne das Angebot dauerhaft zu entfernen.

1. Öffnen Sie das Angebot aus Ihrer Angebotsliste
2. Wählen Sie den aktuellen Status
3. Wählen Sie **Abgelehnt** aus dem Dropdown

Dies führt zu einer Aufzeichnung des Angebots, erhält Ihren Angebotsverlauf und erstellt keine Lücken in Ihrer Nummerierungsfolge.

### Option 2: In Entwurf zurückversetzen

Wenn Sie Änderungen vornehmen müssen, bevor Sie entscheiden, was mit dem Angebot zu tun ist, versetzen Sie es in den Entwurfsstatus zurück.

1. Öffnen Sie das Angebot aus Ihrer Angebotsliste
2. Wählen Sie den aktuellen Status
3. Wählen Sie **Entwurf** aus dem Dropdown

Dies ermöglicht es Ihnen, die Angebotdetails zu bearbeiten, bevor Sie es erneut versenden oder stornieren.

### Option 3: Angebot löschen

Als letztes Mittel können Sie das Angebot dauerhaft löschen.

1. Lokalisieren Sie das Angebot in Ihrer Angebotsliste
2. Wählen Sie die Dropdown-Optionen auf der rechten Seite
3. Wählen Sie **Löschen**

:::warning
Das Löschen eines Angebots entfernt es dauerhaft aus Ihren Aufzeichnungen. Diese Aktion kann nicht rückgängig gemacht werden.
:::

## Änderung des Angebotsstatus

Sie können den Status eines oder mehrerer Angebote direkt aus der Angebotsliste ändern, ohne jedes einzeln zu öffnen.

1. Wählen Sie ein oder mehrere Angebote aus der Liste
2. Wählen Sie **Status**
3. Wählen Sie den neuen Status aus dem Dropdown

## Weitere Aktionen

Aus der Angebotsliste können Sie ein PDF herunterladen, einen Freigabelink generieren, Angebote duplizieren oder löschen. Die Duplizierung ist nützlich, wenn Sie ein ähnliches Angebot für einen anderen Kunden erstellen müssen. Das Löschen ist nur in der Angebotslisten-Ansicht verfügbar.

## Best Practices

Überprüfen Sie regelmäßig Ihre offenen Angebote, damit nichts auf eine Antwort wartet. Bevor Sie Änderungen an einem versendeten Angebot speichern, überprüfen Sie alle Details doppelt, um zu vermeiden, dass falsche Informationen an Ihren Kunden gesendet werden.

:::tip
Konsultieren Sie immer Ihren Buchhalter oder die zuständige Steuerbehörde, um die korrekte Handhabung stornierter Angebote in Ihrer Region zu klären.
:::

## Häufige Probleme

<details>
<summary>Mein Freigabelink für Angebote funktioniert nicht</summary>

Wenn ein Kunde meldet, dass Ihr Freigabelink nicht funktioniert, wurde das Angebot möglicherweise in den Entwurfsstatus zurückversetzt. Während des Entwurfs sind Freigabelinks deaktiviert. Um den Link wiederherzustellen, setzen Sie das Angebot zurück in den Status **Versendet**.

</details>

<details>
<summary>Ich kann mein versendetes Angebot nicht bearbeiten</summary>

Sie können ein Angebot direkt nur im Status **Entwurf** bearbeiten. Um ein versendetes Angebot zu bearbeiten, öffnen Sie es, wählen Sie den aktuellen Status und wählen Sie **Entwurf**. Nehmen Sie Ihre Änderungen vor und speichern Sie. Setzen Sie es dann zurück auf **Versendet**, um den Freigabelink wiederherzustellen.

</details>
