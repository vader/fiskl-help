Dieses Handbuch erklärt, wie Sie Ihre erste Rechnung in Fiskl erstellen, und hilft Ihnen, wichtige Einstellungen für professionelle, steuergerechte Rechnungen zu konfigurieren.

## Vor dem Erstellen Ihrer ersten Rechnung

Die Konfiguration wichtiger Einstellungen vor dem Erstellen Ihrer ersten Rechnung gewährleistet Genauigkeit und Professionalität. Führen Sie diese Einrichtungsschritte aus, um später Rechnungen nicht bearbeiten zu müssen.

**Wichtige Einrichtungs-Checkliste:**
- [ ] Steuereinstellungen konfigurieren (falls Sie Steuern berechnen)
- [ ] Firmeninformationen und Branding einrichten
- [ ] Rechnungsvorlagen anpassen
- [ ] Spracheinstellungen konfigurieren (falls Sie Rechnungen in verschiedenen Sprachen ausstellen)
- [ ] E-Mail-Vorlagen einrichten

Diese Einstellungen nehmen 10-15 Minuten in Anspruch, rationalisieren aber alle zukünftigen Rechnungen.

## Schritt 1: Steuereinstellungen konfigurieren

Falls Sie Steuern auf Produkte oder Dienstleistungen berechnen, konfigurieren Sie die Steuereinstellungen vor dem Erstellen von Rechnungen.

### Richten Sie Ihre Steuerbehörde ein

1. Gehen Sie zu **Einstellungen** > **Steuern**
2. Wählen Sie **Steuernummer hinzufügen**
3. Geben Sie die Details Ihrer Steuerbehörde ein:
   - Name der Steuerbehörde (z. B. „Mehrwertsteuer DE", „Umsatzsteuer AT")
   - Steuernummer
   - Steuertyp (Umsatzsteuer, Mehrwertsteuer, Verbrauchssteuer usw.)
4. Wählen Sie **Speichern**

Fiskl erstellt automatisch ein entsprechendes Sachkonto in Ihrem Kontenrahmen für diese Steuer.

### Fügen Sie Steuersätze hinzu

Konfigurieren Sie die spezifischen Steuersätze, die Sie berechnen:

1. Gehen Sie in den **Steuereinstellungen** zum Abschnitt **Einzelne Steuern**
2. Wählen Sie **Steuer hinzufügen**
3. Konfigurieren Sie die Steuer:
   - Steuername (z. B. „Standard Mehrwertsteuer 20%")
   - Steuersatz in Prozent
   - Zuordnung zu Ihrer Steuerbehörde (Steuernummer)
   - Als Umsatzsteuer oder Nicht-Umsatzsteuer kennzeichnen
4. Wählen Sie **Speichern**

**Beispiel mehrerer Steuersätze:**
- Standardsatz: 20%
- Ermäßigter Satz: 5%
- Nullsatz: 0%

### Legen Sie Standard-Steuersätze fest

Konfigurieren Sie Standard-Steuern, die automatisch auf neue Rechnungen angewendet werden:

1. Suchen Sie in den **Steuereinstellungen** Ihren primären Steuersatz
2. Kennzeichnen Sie ihn als Standard für Verkäufe
3. Wählen Sie **Speichern**

Diese Steuer wird automatisch auf alle Posten angewendet, sofern nicht anders angegeben.

**Weitere Informationen:** [Steuereinstellungen](/settings/tax-settings.md)

## Schritt 2: Richten Sie Firmeninformationen und Branding ein

Ihre Firmeninformationen werden auf jeder Rechnung angezeigt. Konfigurieren Sie sie einmalig für konsistentes Branding.

### Fügen Sie Firmendetails hinzu

1. Gehen Sie zu **Einstellungen** > **Firma**
2. Vervollständigen Sie Ihre Firmeninformationen:
   - Offizieller Firmenname
   - Geschäftsadresse
   - Telefonnummer
   - E-Mail-Adresse
   - Website
   - Geschäftsregistrierungsnummer
3. Laden Sie Ihr Firmenlogo hoch
4. Wählen Sie **Speichern**

### Konfigurieren Sie Rechnungsvorlagen und Marken

Vorlagen steuern das Aussehen und den Inhalt Ihrer Rechnungen.

1. Gehen Sie zu **Einstellungen** > **Vorlagen und Marken**
2. Wählen Sie **Neue Vorlage hinzufügen** oder bearbeiten Sie die Standard-Vorlage
3. Passen Sie die Vorlage an:

**Name & Kopfzeile:**
- Vorlagenname (nur zur internen Verwendung)
- Logo hochladen (wird auf Rechnungen angezeigt)
- Logogröße anpassen
- E-Mail-Logo hochladen (quadratisch, max. 100 KB, wird bei 70x70 Pixeln angezeigt)

**Markenüberschreibungen:**

Falls Sie mehrere Marken unter einer Entität betreiben, überschreiben Sie Firmendetails:
- Firmenname
- Adresse
- Kontaktinformationen
- Logo

Dies erstellt separate gebrandete Rechnungen ohne mehrere Konten.

**Farben & Schriftarten:**
- Wählen Sie Markenfarben für Kopfzeilen und Akzente
- Passen Sie Schriftstile an
- Sehen Sie Änderungen in Echtzeit

**Rechnungs-Layout:**
- Wählen Sie Layoutstil (Klassisch, Modern, Minimalistisch)
- Wählen Sie, welche Felder angezeigt werden sollen
- Passen Sie Abstände und Formatierung an

**Weitere Informationen:** [Rechnungsvorlagen](/settings/invoice-template-brands-settings.md)

## Schritt 3: Konfigurieren Sie Spracheinstellungen

Falls Sie Kunden in mehreren Sprachen Rechnungen ausstellen, konfigurieren Sie die Spracheinstellungen vor dem Erstellen von Rechnungen.

### Legen Sie Ihre Standardsprache fest

1. Gehen Sie zu **Einstellungen** > **Rechnungs- und Angebots-Einstellungen**
2. Wählen Sie unter **Spracheinstellungen** Ihre primäre Sprache
3. Wählen Sie **Speichern**

Alle neuen Rechnungen verwenden diese Sprache standardmäßig. Sie können die Sprache für einzelne Rechnungen bei Bedarf ändern.

**Unterstützte Funktionen:**
- Über 60 Sprachen verfügbar
- Rechnungs- und Angebots-Übersetzungen
- E-Mail-Vorlagen-Übersetzungen
- Kundenorientierte Zahlungsbildschirme
- Zahlungsplan-Schnittstellen

### Passen Sie Sprachübersetzungen an (Optional)

Erstellen Sie benutzerdefinierte Sprachversionen für regionale Dialekte oder spezifische Terminologie:

1. Wählen Sie in den **Spracheinstellungen** **Sprache klonen**
2. Wählen Sie die Grundsprache zum Anpassen
3. Bearbeiten Sie Übersetzungen:
   - Ändern Sie Terminologie für Ihr Unternehmen
   - Passen Sie regionale Dialekte an
   - Passen Sie Feldbezeichnungen an
4. Speichern Sie Ihre benutzerdefinierte Sprache

Ihre benutzerdefinierte Sprache wird im Sprachselektor beim Erstellen von Rechnungen angezeigt.

**Weitere Informationen:** [Rechnungs- und Angebots-Einstellungen](/settings/invoice-quotes-settings)

## Schritt 4: Konfigurieren Sie E-Mail-Vorlagen

Fiskl sendet E-Mail-Benachrichtigungen für Rechnungen, Erinnerungen und Verzugsanzeigen. Konfigurieren Sie Ihre E-Mail-Strategie vor dem Versand von Rechnungen.

### Wählen Sie Ihre E-Mail-Strategie

Fiskl bietet zwei E-Mail-Ansätze:

**Option 1: Fiskl HTML-E-Mail-Vorlagen (Empfohlen)**

Vordefinierte, übersetzte HTML-E-Mails, die automatisch Ihrer Rechnungssprache entsprechen.

**Vorteile:**
- Professionelle HTML-Formatierung
- Automatische Übersetzung in die Rechnungssprache
- Konsistentes Branding
- Enthält dynamische Platzhalter
- Funktioniert für Rechnungen, Erinnerungen, Verzugsanzeigen und wiederkehrende Rechnungen

**Option 2: Benutzerdefinierter E-Mail-Text**

Schreiben Sie Ihren eigenen E-Mail-Inhalt mit vollständiger Kontrolle über die Formulierung.

**Vorteile:**
- Vollständige Anpassung
- Ihr spezifischer Ton und Ihre Stimme
- Benutzerdefinierte Nachrichten pro Szenario
- Enthält weiterhin dynamische Platzhalter

### Konfigurieren Sie E-Mail-Vorlagen

1. Gehen Sie zu **Einstellungen** > **Vorlagen und Marken**
2. Wählen Sie Ihre Vorlage
3. Scrollen Sie zu **E-Mail-Einstellungen**
4. Wählen Sie Ihre E-Mail-Strategie:
   - **Fiskl-Vorlagen verwenden** - Wählen Sie dies für übersetzte HTML-E-Mails
   - **Benutzerdefinierten Text verwenden** - Wählen Sie dies, um Ihren eigenen Text zu schreiben

**Falls Sie benutzerdefinierten E-Mail-Text verwenden:**

1. Konfigurieren Sie E-Mails für jedes Szenario:
   - Neue Rechnungs-E-Mail
   - Zahlungs-Erinnerungs-E-Mail
   - Verzugsanzeige-E-Mail
   - Wiederkehrende Rechnungs-E-Mail
2. Schreiben Sie Ihren E-Mail-Inhalt
3. Verwenden Sie Platzhalter für dynamische Informationen

### E-Mail-Platzhalter

Platzhalter werden automatisch mit Rechnungsdaten gefüllt:

**Allgemeine Platzhalter:**
- `{invoice_number}` - Rechnungsnummer
- `{invoice_date}` - Rechnungsdatum
- `{due_date}` - Fälligkeitsdatum
- `{client_name}` - Kundenname
- `{company_name}` - Ihr Firmenname
- `{invoice_total}` - Gesamtbetrag
- `{invoice_link}` - Link zum Online-Anzeigen der Rechnung

**Beispiel-Benutzeremail:**

```
Subject: Rechnung {invoice_number} von {company_name}

Lieber {client_name},

Vielen Dank für Ihre Geschäftsbeziehung. Anbei finden Sie Rechnung {invoice_number}
für {invoice_total}.

Die Zahlung ist bis {due_date} fällig.

Anzeigen und bezahlen Sie online: {invoice_link}

Beste Grüße,
{company_name}
```

Die Platzhalter funktionieren in allen E-Mail-Typen und gewährleisten Konsistenz.

## Schritt 5: Erstellen Sie Ihre erste Rechnung

Nun da die Einstellungen konfiguriert sind, erstellen Sie Ihre erste Rechnung.

### Starten Sie eine neue Rechnung

1. Gehen Sie zu **Rechnungen** in der linken Navigation
2. Wählen Sie **Neue Rechnung**
3. Der Rechnungserstellungsbildschirm öffnet sich

### Fügen Sie Kundeninformationen hinzu

**Falls der Kunde bereits vorhanden ist:**
1. Wählen Sie den Kunden aus der **Kunden**-Dropdown
2. Seine Details werden automatisch gefüllt

**Falls dies ein neuer Kunde ist:**
1. Wählen Sie **Neuen Kunden hinzufügen**
2. Geben Sie Kundendetails ein:
   - Kundenname
   - E-Mail-Adresse
   - Rechnungsadresse
   - Telefonnummer (optional)
3. Wählen Sie **Speichern**

### Legen Sie Rechnungsdetails fest

Konfigurieren Sie die Rechnungsparameter:

**Rechnungsnummer:**
- Automatisch basierend auf Ihrer Sequenz generiert
- Bearbeitbar, falls erforderlich

**Rechnungsdatum:**
- Standardwert: heute
- Ändern Sie es, falls Sie für ein anderes Datum ausstellen

**Fälligkeitsdatum:**
- Legen Sie Zahlungsfrist fest
- Verwendet Ihre Standard-Zahlungsbedingungen

**Sprache:**
- Standard: Ihre primäre Sprache
- Ändern Sie dies für diese spezifische Rechnung, falls erforderlich

**Vorlage:**
- Wählen Sie, welche Vorlage verwendet werden soll
- Ändern Sie, falls Sie mehrere Vorlagen/Marken verwenden

### Fügen Sie Positionen hinzu

Fügen Sie Produkte oder Dienstleistungen zu Ihrer Rechnung hinzu:

1. Wählen Sie **Position hinzufügen**
2. Geben Sie Positionsdetails ein:
   - Beschreibung (Produkt- oder Dienstleistungsname)
   - Menge
   - Stückpreis
   - Steuersatz (Standard: Ihr primärer Steuersatz)
3. Der Betrag wird automatisch berechnet

**Fügen Sie weitere Positionen hinzu:**
- Wählen Sie **Position hinzufügen** für jedes Produkt oder Dienstleistung
- Fiskl berechnet Zwischensummen und Gesamtsummen automatisch

**Produktbibliothek:**

Falls Sie Produkte oder Dienstleistungen gespeichert haben:
1. Wählen Sie **Aus Bibliothek auswählen**
2. Wählen Sie das Produkt
3. Details werden automatisch gefüllt

### Wenden Sie Rabatte an (Optional)

Fügen Sie Rabatte auf Positionen oder die gesamte Rechnung an:

**Positions-Rabatt:**
1. Wählen Sie die Position
2. Geben Sie Rabatt in Prozent oder Betrag ein
3. Die Position berechnet den rabattierten Preis

**Rechnungs-Rabatt:**
1. Scrollen Sie zum Abschnitt Rechnungssumme
2. Geben Sie Rabatt in Prozent oder Betrag ein
3. Die Gesamtsumme wird automatisch aktualisiert

### Fügen Sie Notizen und Bedingungen hinzu (Optional)

**Rechnungsnotizen:**
- Fügen Sie Notizen hinzu, die für den Kunden sichtbar sind
- Enthalten Sie Projektdetails oder spezielle Anweisungen

**Zahlungsbedingungen:**
- Fügen Sie Zahlungsbedingungen und -bedingungen hinzu
- Enthalten Sie Richtlinien für verspätete Zahlungen

### Überprüfen Sie die Steuerberechnung

Überprüfen Sie vor der Fertigstellung die Steuerberechnung:

1. Überprüfen Sie, dass die Steuer auf entsprechende Positionen angewendet wird
2. Bestätigen Sie, dass der Steuersatz korrekt ist
3. Überprüfen Sie den Steuerbetrag in der Gesamtsumme
4. Bestätigen Sie den Gesamtbetrag inklusive Steuern

Falls die Steuer nicht korrekt berechnet wird, überprüfen Sie Ihre Steuereinstellungen und Positions-Steuerzuweisungen.

## Schritt 6: Vorschau anzeigen und Ihre Rechnung versenden

### Zeigen Sie eine Vorschau der Rechnung an

1. Wählen Sie **Vorschau**
2. Überprüfen Sie die Rechnung, wie Ihr Kunde sie sieht
3. Überprüfen Sie alle Details:
   - Kundeninformationen sind korrekt
   - Positionen sind genau
   - Steuern werden korrekt berechnet
   - Gesamtsummen sind korrekt
   - Branding sieht professionell aus

### Speichern oder versenden

**Option 1: Als Entwurf speichern**

Falls Sie später fertig werden müssen:
1. Wählen Sie **Als Entwurf speichern**
2. Die Rechnung wird zur späteren Bearbeitung gespeichert
3. Finden Sie es unter **Rechnungen** mit dem Status Entwurf

**Option 2: An Kunden versenden**

Wenn Sie bereit sind zu versenden:
1. Wählen Sie **Rechnung versenden**
2. Überprüfen Sie die E-Mail-Vorschau
3. Bearbeiten Sie die E-Mail-Nachricht, falls erforderlich (falls Sie benutzerdefinierte E-Mails verwenden)
4. Wählen Sie **Versenden**

Der Kunde erhält die Rechnung per E-Mail mit einem Link zum Online-Anzeigen und Bezahlen.

**Option 3: PDF herunterladen**

Zum manuellen Versand oder Drucken:
1. Wählen Sie **PDF herunterladen**
2. Die Rechnung wird als PDF-Datei heruntergeladen
3. Anhängen an Ihre eigene E-Mail oder drucken

## Nach dem Versand Ihrer Rechnung

### Verfolgen Sie den Rechnungsstatus

Überwachen Sie Ihre Rechnung im Abschnitt **Rechnungen**:

**Statusindikatoren:**
- **Entwurf** - Noch nicht versandt
- **Versandt** - An Kunde versandt, warten auf Zahlung
- **Angesehen** - Kunde hat die Rechnung geöffnet
- **Teilweise bezahlt** - Teilzahlung erhalten
- **Bezahlt** - Vollständig bezahlt
- **Überfällig** - Nach Fälligkeitsdatum, unbezahlt

### Zahlungen erfassen

Wenn ein Kunde zahlt:

1. Gehen Sie zu **Rechnungen**
2. Wählen Sie die Rechnung
3. Wählen Sie **Zahlung erfassen**
4. Geben Sie Zahlungsdetails ein:
   - Zahlungsbetrag
   - Zahlungsdatum
   - Zahlungsmethode
   - Bankkonto (wohin die Gelder eingegangen sind)
5. Wählen Sie **Speichern**

Der Rechnungsstatus wird auf Bezahlt aktualisiert und die Transaktion in Ihre Buchhaltung erfasst.

### Versenden Sie Erinnerungen

Falls eine Rechnung unbezahlt ist:

1. Wählen Sie die Rechnung
2. Wählen Sie **Erinnerung versenden**
3. Wählen Sie Erinnerungstyp:
   - Freundliche Erinnerung (vor Fälligkeitsdatum)
   - Zahlungs-Erinnerung (bei Fälligkeitsdatum)
   - Verzugsanzeige (nach Fälligkeitsdatum)
4. Überprüfen Sie die E-Mail-Vorschau
5. Wählen Sie **Versenden**

Erinnerungs-E-Mails verwenden die Vorlagen, die Sie zuvor konfiguriert haben.

## Häufige Rechnungsszenarien

### Rechnungstellung in mehreren Währungen

Falls Ihr Kunde eine andere Währung verwendet:

1. Wählen Sie beim Erstellen der Rechnung die Währungs-Dropdown
2. Wählen Sie die Währung Ihres Kunden
3. Geben Sie Beträge in dieser Währung ein
4. Fiskl konvertiert für Berichtszwecke in Ihre Basiswährung

Wechselkurse werden automatisch aktualisiert.

### Wiederkehrende Rechnungen

Für regelmäßige Kunden mit regulärer Abrechnung:

1. Erstellen Sie die erste Rechnung wie gewohnt
2. Wählen Sie **Wiederkehrend machen**
3. Konfigurieren Sie den Zeitplan:
   - Häufigkeit (wöchentlich, monatlich, jährlich)
   - Startdatum
   - Enddatum oder Anzahl der Vorkommen
4. Wählen Sie **Speichern**

Fiskl generiert und versendet Rechnungen automatisch nach dem Zeitplan.

### Leistungsrechnungen

Für projektbasierte Arbeit mit Meilensteinen:

1. Erstellen Sie die erste Rechnung für den ersten Meilenstein
2. Kennzeichnen Sie sie als Teilrechnung
3. Geben Sie den Prozentsatz oder Betrag ein
4. Erstellen Sie nachfolgende Rechnungen mit Verweis auf das Original
5. Fiskl verfolgt die Gesamtabrechnung gegenüber dem Projektwert

## Best Practices für Rechnungstellung

### Vor dem Erstellen von Rechnungen

- [ ] Führen Sie alle Setup-Konfigurationen durch
- [ ] Testen Sie mit einer Beispielrechnung für sich selbst
- [ ] Stellen Sie sicher, dass Steuerberechnungen korrekt sind
- [ ] Bestätigen Sie, dass E-Mail-Vorlagen korrekt angezeigt werden
- [ ] Überprüfen Sie, dass Branding Ihrer Identität entspricht

### Beim Erstellen von Rechnungen

- [ ] Verwenden Sie klare, detaillierte Positionsbeschreibungen
- [ ] Fügen Sie Projekt- oder Bestellnummern in Notizen ein
- [ ] Legen Sie realistische Fälligkeitsdaten fest (typisch Netto 30)
- [ ] Überprüfen Sie Kundenemails doppelt
- [ ] Zeigen Sie eine Vorschau vor dem Versand an

### Nach dem Versand von Rechnungen

- [ ] Überwachen Sie den Rechnungsstatus regelmäßig
- [ ] Versenden Sie Erinnerungen für bevorstehende Fälligkeitsdaten
- [ ] Verfolgen Sie prompte fällige Rechnungen nach
- [ ] Erfassen Sie Zahlungen sobald sie eingehen
- [ ] Stimmen Sie Rechnungszahlungen mit Banktransaktionen ab

### Für professionelle Ergebnisse

- [ ] Verwenden Sie konsistente Vorlagen in allen Rechnungen
- [ ] Enthalten Sie vollständige Zahlungsanweisungen
- [ ] Fügen Sie Ihr Logo und Branding hinzu
- [ ] Bieten Sie mehrere Zahlungsmethoden
- [ ] Versenden Sie Dankesnoten bei Zahlungsempfang

## Fehlerbehebung häufiger Probleme

### Steuer wird nicht korrekt berechnet

**Ursache:** Steuereinstellungen nicht konfiguriert oder Positionen vermissen Steuerzuweisung

**Lösung:**
1. Überprüfen Sie, dass Steuersätze in **Einstellungen** > **Steuern** eingerichtet sind
2. Überprüfen Sie, dass Steuer den Positionen zugewiesen ist
3. Bestätigen Sie, dass Standard-Steuersatz konfiguriert ist
4. Überprüfen Sie, dass steuerbefreite Positionen korrekt gekennzeichnet sind

### E-Mail wird nicht versandt

**Ursache:** Kundenemails-Adresse ist falsch oder E-Mail-Zustellungsprobleme

**Lösung:**
1. Überprüfen Sie, dass Kundenemaila-Adresse korrekt ist
2. Überprüfen Sie Ihre E-Mail-Versendungslimits
3. Bitten Sie Kunden, Spam-Ordner zu prüfen
4. Verwenden Sie **Rechnung erneut versenden** zum erneuten Versuch
5. Laden Sie PDF herunter und versenden Sie manuell, falls Probleme anhalten

### Rechnungsnummernfolge falsch

**Ursache:** Manuelle Nummerierung oder Sequenz-Konfiguration

**Lösung:**
1. Gehen Sie zu **Einstellungen** > **Rechnungs- und Angebots-Einstellungen**
2. Überprüfen Sie Rechnungsnummern-Sequenz-Einstellungen
3. Passen Sie die nächste Rechnungsnummer an, falls erforderlich
4. Erwägen Sie die Verwendung von automatischer sequenzieller Nummerierung

### Vorlage wird nicht korrekt angezeigt

**Ursache:** Logo-Größe-Probleme oder Fehler bei Vorlagenanpassung

**Lösung:**
1. Überprüfen Sie Logo-Dimensionen (empfohlen max. 800 Pixel breit)
2. Überprüfen Sie, dass Vorlageneinstellungen korrekt gespeichert wurden
3. Löschen Sie den Browser-Cache und zeigen Sie Vorschau erneut an
4. Versuchen Sie eine andere Vorlage, um das Problem zu isolieren

### Kunde kann Rechnung online nicht anzeigen

**Ursache:** E-Mail-Link-Probleme oder Browser-Kompatibilität

**Lösung:**
1. Versenden Sie die Rechnungs-E-Mail erneut
2. Bitten Sie Kunden, Spam-Ordner zu prüfen
3. Laden Sie PDF herunter und versenden Sie direkt
4. Bestätigen Sie, dass Rechnung nicht im Entwurfsstatus ist
