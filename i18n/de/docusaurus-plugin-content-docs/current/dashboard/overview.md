# Dashboard

Ihr Fiskl Dashboard ist Ihr Geschäftskontrollzentrum. Es bietet Ihnen Echtzeiteinblick in Ihre finanzielle Leistung, ausstehende Rechnungen, Ausgaben und Bankaktivitäten über alle Ihre verbundenen Konten.

## Warum das Dashboard verwenden

Das Dashboard zentralisiert Ihre wichtigsten Geschäftsdaten an einem Ort. Anstatt durch mehrere Abschnitte zu navigieren, um Ihren Status zu überprüfen, können Sie alles auf einen Blick sehen und sofort handeln.

**Hauptvorteile:**
- Überwachen Sie Umsatz, Ausgaben und Kapitalflussrechnung in Echtzeit
- Verfolgen Sie überfällige Rechnungen und ausstehende Zahlungen
- Zeigen Sie kürzliche Transaktionen über alle verbundenen Banken an
- Greifen Sie mit Schnellaktionen auf häufig verwendete Funktionen zu
- Passen Sie Abschnitte an Ihren Arbeitsablauf an

## Wichtige Konzepte

Das Verständnis dieser Elemente hilft Ihnen, das Beste aus Ihrem Dashboard herauszuholen:

- **Widgets**: Einzelne Abschnitte, die spezifische Metriken oder Daten anzeigen (z. B. Umsatzdiagramm, Aktuelle Rechnungen)
- **Schnellaktionen**: Verknüpfungen zu häufigen Aufgaben wie dem Erstellen von Rechnungen oder dem Erfassen von Ausgaben
- **Basiswährung**: Die primäre Währung, die Ihr Dashboard für Berichte und Berechnungen verwendet
- **Zeitraumfilter**: Steuerelemente, die Datumsbereiche für Metriken und Diagramme anpassen
- **Widget-Sichtbarkeit**: Ihre Möglichkeit, bestimmte Dashboard-Abschnitte ein- oder auszublenden

## Funktionsweise

Das Dashboard wird automatisch aktualisiert, wenn Sie in Fiskl arbeiten. Wenn Sie eine Rechnung erstellen, eine Ausgabe erfassen oder Ihre Bankkonten synchronisieren, werden die relevanten Widgets aktualisiert, um die neuen Daten widerzuspiegeln.

1. **Echtzeitaktualisierungen**: Metriken werden sofort aktualisiert, wenn Sie Transaktionen abschließen
2. **Anpassbares Layout**: Zeigen Sie nur die Widgets an, die für Ihr Geschäft und Ihre Rolle relevant sind
3. **Schnellzugriff**: Navigieren Sie zu detaillierten Ansichten, indem Sie ein Widget oder eine Metrik auswählen
4. **Rollengesteuerte Anzeige**: Das Dashboard passt sich Ihren Benutzerberechtigungen an

## Standardmäßige Dashboard-Abschnitte

Ihr Dashboard zeigt je nach Ihren Berechtigungen verschiedene Abschnitte an:

**Für vollständigen Kontozugriff:**
- Schlüsselmetriken (Umsatz, Ausgaben, Gewinn, Kassenbestand)
- Kapitalflussdiagramm
- Finanzkennzahlen
- Rechnungsübersicht
- Fälligkeitsbericht Forderungen
- Fälligkeitsbericht Verbindlichkeiten
- Bankaktivität
- Zusammenfassung der Zeiterfassung
- Kilometerstandzusammenfassung

**Für Abrechnung und Rechnungslegungszugriff:**
- Rechnungsübersicht
- Zusammenfassung der Zeiterfassung
- Kilometerstandzusammenfassung

**Für eingeschränkten Zugriff:**
- Zusammenfassung der Zeiterfassung
- Kilometerstandzusammenfassung

:::tip
Sie können anpassen, welche Abschnitte angezeigt werden und deren Reihenfolge. Siehe [Ihr Dashboard anpassen](./customizing-dashboard), um Ihre Ansicht zu personalisieren.
:::

## Erste Schritte

Nach dem Anmelden werden Sie direkt auf Ihr Dashboard weitergeleitet. Von hier aus:

1. **Überprüfen Sie Ihre Schlüsselmetriken** im oberen Abschnitt
2. **Prüfen Sie auf dringende Elemente** wie überfällige Rechnungen, die in Rot hervorgehoben sind
3. **Verwenden Sie Schnellaktionen** oben rechts, um neue Datensätze zu erstellen
4. **Wählen Sie ein Widget** aus, um detaillierte Informationen anzuzeigen
