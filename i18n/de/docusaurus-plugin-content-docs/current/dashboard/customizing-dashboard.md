# Dashboard anpassen

Dieses Handbuch erläutert, wie Sie Ihr Dashboard personalisieren, indem Sie steuern, welche Widgets angezeigt werden und in welcher Reihenfolge. So können Sie sich auf die Metriken konzentrieren, die für Ihr Unternehmen am wichtigsten sind.

## Öffnen des Konfigurationsbereichs

Um den Dashboard-Konfigurationsbereich zu öffnen, gehen Sie zum **Dashboard** und wählen Sie das Symbol **Dashboard anpassen** in der oberen rechten Ecke. Der Konfigurationsbereich wird geöffnet und zeigt alle verfügbaren Dashboard-Abschnitte mit Steuerelementen zum Anzeigen, Ausblenden und Neuordnen an.

## Widget-Sichtbarkeit verstehen

Jeder Dashboard-Abschnitt kann unabhängig angezeigt oder ausgeblendet werden. Sichtbare Widgets werden auf Ihrem Dashboard angezeigt; ausgeblendete Widgets werden aus der Ansicht entfernt, bleiben aber verfügbar, um sie jederzeit zu aktivieren.

Ihr Berechtigungsstufe bestimmt, auf welche Widgets Sie zugreifen können:

| Berechtigungsstufe | Verfügbare Widgets |
|---|---|
| **Vollständiger Kontenzugriff** | Wichtige Metriken, Kapitalflussrechnung, Kennzahlen, Invoicing, Forderungen/Verbindlichkeiten Fälligkeitsbericht, Banking, Zeit, Kilometerstand |
| **Abrechnung & Invoicing** | Invoicing, Zeit, Kilometerstand |
| **Eingeschränkter Zugriff** | Zeit, Kilometerstand |

:::info
Wenn Sie über begrenzte Berechtigungen verfügen, zeigt der Konfigurationsbereich ein Informationsbanner an, das erklärt, welche Widgets basierend auf Ihrer Rolle verfügbar sind.
:::

## Widgets anzeigen oder ausblenden

1. Öffnen Sie den Konfigurationsbereich.
2. Suchen Sie das Widget, das Sie anzeigen oder ausblenden möchten.
3. Schalten Sie den Schalter neben dem Widget-Namen um. Blau bedeutet, dass das Widget sichtbar ist; Grau bedeutet, dass es ausgeblendet ist.
4. Die Anzahl oben im Bereich wird aktualisiert, um die Anzahl der sichtbaren und ausgeblendeten Widgets widerzuspiegeln.
5. Wählen Sie **Speichern**.

## Widgets neu ordnen

1. Öffnen Sie den Konfigurationsbereich.
2. Wählen Sie und halten Sie das Griffsymbol (sechs Punkte) auf der linken Seite eines Widgets.
3. Ziehen Sie das Widget nach oben oder unten an die gewünschte Position.
4. Lassen Sie los, um es an der neuen Position zu platzieren. Andere Widgets verschieben sich automatisch, um Platz zu schaffen.
5. Wählen Sie **Speichern**.

Während Sie das Widget ziehen, wird es leicht transparent und eine hervorgehobene Ablage zeigt an, wo es landen wird.

## Speichern Ihrer Konfiguration

Nach vorgenommenen Änderungen wählen Sie **Speichern** in der unteren rechten Ecke des Bereichs. Ihre Konfiguration wird sofort gespeichert, der Bereich schließt sich, und Ihr Dashboard wird mit dem neuen Layout aktualisiert.

:::tip
Die Schaltfläche **Speichern** ist nur aktiv, wenn Sie Änderungen vorgenommen haben. Wenn sie ausgegraut erscheint, wurden noch keine Änderungen vorgenommen.
:::

## Änderungen abbrechen

Wählen Sie **Abbrechen** in der unteren rechten Ecke des Bereichs. Wenn Sie ungespeicherte Änderungen haben, wird eine Bestätigungsaufforderung angezeigt. Bestätigen Sie, um Ihre Änderungen zu verwerfen – der Bereich schließt sich und Ihr Dashboard bleibt unverändert.

## Auf Standard zurücksetzen

Um das ursprüngliche Dashboard-Layout wiederherzustellen, öffnen Sie den Konfigurationsbereich und wählen Sie **Auf Standard zurücksetzen** in der unteren linken Ecke. Eine Bestätigungsaufforderung wird angezeigt. Bestätigen Sie, um alle Widgets auf ihre standardmäßige Sichtbarkeit und Reihenfolge zurückzusetzen, wie sie von Fiskl festgelegt wurde.

:::warning
Das Zurücksetzen entfernt alle Ihre Anpassungen. Diese Aktion kann nicht rückgängig gemacht werden. Sie müssen Ihr Dashboard manuell neu konfigurieren, wenn Sie versehentlich zurücksetzen.
:::

## Best Practices für die Konfiguration

Beginnen Sie mit dem Standard-Layout und verwenden Sie das Dashboard einige Tage, bevor Sie es anpassen. Sie werden schnell erkennen, welche Widgets Sie am häufigsten überprüfen. Sobald Sie ein Gefühl für Ihre Prioritäten bekommen, platzieren Sie die Widgets, die Sie mehrmals täglich überprüfen, oben auf der Liste.

Wenn sich der Fokus Ihres Unternehmens ändert, überprüfen Sie Ihre Konfiguration erneut. Ausgeblendete Widgets bleiben jederzeit verfügbar – es ist nicht erforderlich, ein Widget zu löschen, wenn es genügt, es auszublenden. Eine regelmäßige Überprüfung Ihres Layouts alle paar Monate hält das Dashboard im Einklang damit, wie Ihr Unternehmen gewachsen ist.

## Berechtigungsbasierte Konfigurationen

### Vollständiger Kontenzugriff

Mit vollständigem Zugriff sind alle Widgets verfügbar. Eine empfohlene Ausgangsreihenfolge ist: Wichtige Metriken, Kapitalflussrechnung-Diagramm, Forderungen Fälligkeitsbericht, Invoicing-Zusammenfassung und Banking-Aktivität. Dies gibt Ihnen einen vollständigen Überblick über die Finanzgesundheit, Liquiditätsposition und Kundenabrechnung auf einen Blick.

### Benutzer mit Abrechnung & Invoicing

Mit Abrechnung & Invoicing-Zugriff können Sie die Widgets Invoicing, Zeit und Kilometerstand sehen. Das Platzieren der Invoicing-Zusammenfassung oben erleichtert die Verfolgung der Kundenabrechnung auf einen Blick, gefolgt von Zeitzusammenfassung und Kilometerstand-Zusammenfassung für Protokollierungs- und Erstattungszwecke.

### Benutzer mit eingeschränktem Zugriff

Mit eingeschränktem Zugriff sind nur die Widgets Zeit und Kilometerstand verfügbar. Platzieren Sie die Zeitzusammenfassung an erster Stelle, wenn die Stundenprotokollierung Ihre primäre Aufgabe ist, oder die Kilometerstand-Zusammenfassung an erster Stelle, wenn die Kilometerstandverfolgung Vorrang hat.

## Häufig auftretende Probleme

<details className="blue-box">
<summary>Änderungen werden nicht gespeichert</summary>

Überprüfen Sie Ihre Internetverbindung und versuchen Sie, **Speichern** erneut auszuwählen. Wenn das Problem weiterhin besteht, aktualisieren Sie die Seite und konfigurieren Sie Ihr Layout neu.

</details>

<details className="blue-box">
<summary>Ein Widget wird nach dem Aktivieren nicht angezeigt</summary>

Bestätigen Sie, dass Sie **Speichern** statt **Abbrechen** gewählt haben. Scrollen Sie das Dashboard nach unten – das Widget kann sich unterhalb des sichtbaren Bereichs befinden. Wenn es immer noch nicht angezeigt wird, aktualisieren Sie die Seite, um ein erneutes Laden zu erzwingen.

</details>

<details className="blue-box">
<summary>Ein Widget, das Sie benötigen, ist nicht verfügbar</summary>

Ihre Berechtigungsstufe bestimmt, welche Widgets im Konfigurationsbereich sichtbar sind. Überprüfen Sie das Informationsbanner im Bereich und kontaktieren Sie Ihren Kontoadministrator, um zusätzlichen Zugriff anzufordern.

</details>
