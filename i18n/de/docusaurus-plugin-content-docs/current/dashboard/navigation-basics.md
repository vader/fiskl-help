# Dashboard-Navigation Grundlagen

Dieses Handbuch erklärt, wie Sie durch Ihr Fiskl-Dashboard navigieren und verschiedene Bereiche der Anwendung effizient aufrufen.

## Das Layout verstehen

Fiskl verwendet ein dreiteiliges Layout:

1. **Linke Seitenleiste**: Hauptnavigationsmenü mit erweiterbaren Abschnitten
2. **Oberer Header**: Suche, Schnellaktionen, Benachrichtigungen und Benutzermenü
3. **Hauptinhaltsbereich**: Das Dashboard oder der ausgewählte Seiteninhalt

## Das Seitenleistenmenü verwenden

Die Seitenleiste organisiert Funktionen in logische Gruppen:

### Hauptnavigationsabschnitte

**Dashboard**
- Ihre Startseite mit wichtigen Metriken und Zusammenfassungen
- Wählen Sie **Dashboard** oben in der Seitenleiste, um jederzeit hierher zurückzukehren

**Verkauf**
- Rechnungen
- Wiederkehrende Rechnungen
- Angebote (falls verfügbar)
- Kunden

**Einkauf**
- Zeiterfassung
- Kilometerstand-Verfolgung
- Lieferanten
- Ausgaben
- KI-Ausgaben (Ausgabenerkennung)

**Buchhaltung**
- Kontenrahmen
- Berichte
- Multi-Journal-Buchungssätze
- Transaktionen

**Produkte & Dienstleistungen**
- Ihr Dienstleistungskatalog und Produktinventar

**Banking**
- Verbundene Bankkonten und Transaktionen

**Teammitglieder**
- Benutzerverwaltung und Berechtigungen

### Menüabschnitte erweitern

Abschnitte mit einem Chevron-Symbol (>) enthalten Untermenüelemente:

1. **Wählen Sie den Abschnittsnamen** (z. B. **Verkauf**)
2. Der Abschnitt wird erweitert und zeigt die verfügbaren Optionen
3. **Wählen Sie ein Untermenüelement**, um zu dieser Seite zu navigieren
4. Der Abschnitt bleibt erweitert, bis Sie ihn ausblenden

### Die Seitenleiste ausblenden

Auf Mobilgeräten oder kleineren Bildschirmen:

1. **Wählen Sie das Menüsymbol** (drei horizontale Linien) oben links
2. Die Seitenleiste wird von links eingeklappt
3. **Wählen Sie außerhalb der Seitenleiste** oder das Schließsymbol, um sie auszublenden

## Schnellaktionen verwenden

Die Schaltfläche **Schnellaktionen** oben rechts bietet Verknüpfungen zu häufigen Aufgaben:

**So verwenden Sie Schnellaktionen:**

1. Wählen Sie **+ Schnellaktionen** oben rechts
2. Wählen Sie aus Optionen wie:
    - Rechnung erstellen
    - Ausgabe erfassen
    - Zeit protokollieren
    - Kilometerstand hinzufügen
3. Das relevante Formular wird in einem Modal oder auf einer neuen Seite geöffnet

:::tip
Schnellaktionen passen sich Ihren Berechtigungen an. Sie sehen nur Optionen für Funktionen, auf die Sie zugreifen können.
:::

## Widget-Inhalte navigieren

Dashboard-Widgets sind interaktiv:

**So zeigen Sie Details an:**
1. **Wählen Sie den Widget-Titel** oder den Link **Alle anzeigen**
2. Sie navigieren zur vollständigen Seite dieser Funktion
3. Verwenden Sie die Zurück-Schaltfläche Ihres Browsers oder die Seitenleiste, um zurückzukehren

**Beispiel:**
- Wählen Sie **Alle anzeigen** im Widget Rechnungsverwaltung
- Sie navigieren zur vollständigen Seite Rechnungen
- Wählen Sie **Dashboard** in der Seitenleiste, um zurückzukehren

## Aktive Zustände verstehen

Die Seitenleiste hebt Ihren aktuellen Standort hervor:

- **Fettdruck**: Die aktive Seite, die Sie anzeigen
- **Hintergrundfarbe**: Der aktive Abschnitt ist hervorgehoben
- **Erweiterter Abschnitt**: Die übergeordnete Kategorie Ihrer aktuellen Seite bleibt geöffnet

## Breadcrumb-Navigation

Einige Seiten zeigen Breadcrumbs unter dem Header:

Dashboard > Verkauf > Rechnungen > Rechnung #001

**So navigieren Sie mit Breadcrumbs:**
1. **Wählen Sie eine beliebige Ebene** im Breadcrumb-Pfad
2. Sie navigieren zurück zu diesem Abschnitt
3. Dies bietet eine schnelle Möglichkeit, um eine Ebene aufzusteigen

## Benutzermenü-Optionen

Wählen Sie Ihren Avatar oder Namen unten links in der Seitenleiste, um auf folgende Optionen zuzugreifen:

- **Einstellungen**: Persönliche und Firmeneinstellungen
- **Abonnements & Abrechnung**: Verwalten Sie Ihr Fiskl-Abonnement
- **Abmelden**: Melden Sie sich von Ihrem Konto ab

## Tastaturnavigation

Beschleunigen Sie die Navigation mit Tastaturkürzeln:

| Kürzel | Aktion |
|--------|--------|
| `Ctrl+/` oder `Cmd+/` | Fokus auf Suchleiste |
| `Esc` | Schließen Sie Modals oder Panels |
| `Tab` | Navigieren Sie zwischen Feldern |
| `Enter` | Bestätigen Sie Aktionen |

## Suchfunktionalität

Die Suchleiste im oberen Header findet:

- Rechnungen nach Nummer oder Kundenname
- Ausgaben nach Lieferant oder Beschreibung
- Kunden und Lieferanten nach Name
- Transaktionen nach Betrag oder Konto

**So suchen Sie:**
1. **Wählen Sie die Suchleiste** oder drücken Sie `Ctrl+/`
2. **Geben Sie Ihre Suchbegriffe ein**
3. Die Ergebnisse erscheinen beim Tippen
4. **Wählen Sie ein Ergebnis**, um diesen Datensatz anzuzeigen

## Mobile-Navigation

Auf Mobilgeräten:

1. **Tippen Sie auf das Menüsymbol**, um die Seitenleiste zu öffnen
2. **Tippen Sie auf Abschnittsnamen**, um Untermenüs zu erweitern
3. **Wischen Sie von rechts vom linken Rand**, um die Seitenleiste zu öffnen
4. **Tippen Sie außerhalb** der Seitenleiste, um sie zu schließen

## Berechtigungsbasierte Navigation

Menüelemente passen sich Ihrer Rolle an:

- **Vollständiger Kontozugriff**: Siehe alle Menüabschnitte
- **Abrechnung & Rechnungsverwaltung**: Siehe Verkauf- und Einkaufsabschnitte
- **Eingeschränkter Zugriff**: Nur Zeit und Kilometerstand anzeigen

Wenn Sie ein Menüelement nicht sehen, haben Sie möglicherweise keine Berechtigung. Wenden Sie sich an Ihren Kontoadministrator, um Zugriff anzufordern.

## Tipps für effiziente Navigation

**Verwenden Sie das Dashboard als Ihre Zentrale:**
Kehren Sie häufig zum Dashboard zurück, um Metriken zu überprüfen und auf Schnellaktionen zuzugreifen.

**Halten Sie häufig verwendete Abschnitte erweitert:**
Die Seitenleiste speichert, welche Abschnitte Sie offenlassen.

**Favorisieren Sie bestimmte Seiten:**
Speichern Sie direkte URLs zu Seiten, die Sie häufig besuchen (z. B. die Rechnungsliste).

**Lernen Sie die Tastaturkürzelfunktionen:**
Die Verwendung von `Ctrl+/` für die Suche spart Zeit gegenüber der Verwendung Ihrer Maus.
