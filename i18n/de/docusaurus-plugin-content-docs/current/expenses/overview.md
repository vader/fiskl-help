Dieses Handbuch behandelt Traditionelle Ausgaben — Fiskls ursprüngliches Ausgabensystem. Sie können vorhandene Datensätze anzeigen, bearbeiten und löschen, aber alle neuen Ausgaben müssen über [KI-Ausgaben](/expenses/ai-expenses/overview) erstellt werden.

## Zugriff auf Traditionelle Ausgaben

Traditionelle Ausgaben werden in der linken Seitenleiste als **Ausgaben** angezeigt. Sie sind nur sichtbar, wenn Sie vorhandene Legacy-Datensätze haben.

1. Gehen Sie in der linken Seitenleiste zu **Käufe** > **Ausgaben**.
2. Wählen Sie **Ausgaben**.

## Grundlagen zu Traditionellen Ausgabetypen

Das traditionelle System umfasst zwei Ausgabetypen.

### Eigenständige Ausgaben

Eigenständige Ausgaben werden unabhängig von Banktransaktionen erstellt. Sie werden manuell erfasst und erfordern eine Abstimmung mit einer Bank-, Kreditkarten- oder Kassenkontotransaktion, bevor sie korrekt in Finanzberichten angezeigt werden.

### Direkte Buchhaltungsausgaben

Direkte Buchhaltungsausgaben werden erstellt, wenn Sie eine Banktransaktion kategorisieren. Sie werden sofort in Ihrer Buchhaltung widergespiegelt und erfordern keinen separaten Abstimmungsschritt.

## Was Sie tun können

In Traditionelle Ausgaben können Sie:

- Alle Ausgaben anzeigen, die vor der Verfügbarkeit von KI-Ausgaben erstellt wurden
- Ausgabendetails einschließlich Beträge, Kategorien, Daten und Beschreibungen bearbeiten
- Beleganhänge hinzufügen oder aktualisieren
- Falsche oder doppelte Datensätze löschen
- Daten für Berichte exportieren

Sie können in diesem System keine neuen Ausgaben erstellen.

## Bearbeiten einer Ausgabe

1. Gehen Sie zu **Käufe** > **Ausgaben**.
2. Wählen Sie die Ausgabe aus, die Sie aktualisieren möchten.
3. Aktualisieren Sie die relevanten Felder.
4. Wählen Sie **Speichern**.

## Löschen einer Ausgabe

1. Wählen Sie die Ausgabe aus, die Sie entfernen möchten.
2. Wählen Sie **Löschen**.
3. Bestätigen Sie das Löschen.

:::warning
Das Löschen einer Ausgabe ist permanent. Stellen Sie sicher, dass Sie den Datensatz nicht mehr benötigen, bevor Sie ihn löschen.
:::

## Abstimmung einer eigenständigen Ausgabe

Eigenständige traditionelle Ausgaben müssen manuell mit einer Banktransaktion abgeglichen werden.

1. Gehen Sie zu **Käufe** > **Ausgaben**.
2. Suchen Sie die entsprechende Transaktion auf Ihrem Bank-, Kreditkarten- oder Kassenkonto.
3. Verwenden Sie die Abgleichfunktion, um die Ausgabe mit der Transaktion zu verknüpfen.
4. Überprüfen Sie die Details und bestätigen Sie den Abgleich.

Nach der Abstimmung wird die Ausgabe korrekt in Ihren Finanzberichten angezeigt.

## Verrechenbare Traditionelle Ausgaben

Sie können traditionelle Ausgaben als verrechenbare Positionen zu Kundenrechnungen hinzufügen.

So markieren Sie eine Ausgabe als verrechenbar:

1. Wählen Sie die Ausgabe.
2. Weisen Sie einen **Kunde** zu.
3. Wählen Sie **Speichern**.

So fügen Sie eine verrechenbare Ausgabe zu einer Rechnung hinzu:

1. Öffnen oder erstellen Sie die relevante Rechnung.
2. Fügen Sie die verrechenbare Ausgabe als Position hinzu.

Sobald eine Ausgabe zu einer Rechnung hinzugefügt wird, wird sie als verrechnet markiert und kann nicht auf einer anderen Rechnung verwendet werden.

## Traditionelle Ausgaben in Berichten

Traditionelle Ausgaben werden neben KI-Ausgaben in allen relevanten Finanzberichten angezeigt, einschließlich Gewinn- und Verlustrechnung, Ausgabenkategorieberichte, Lieferantenausgaben und Steuerberichte. Für Legacy-Datensätze ist keine separate Berichterstattung erforderlich.
