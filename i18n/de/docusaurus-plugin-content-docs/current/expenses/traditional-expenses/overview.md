# Traditionelle Ausgaben (Legacy-System)

:::info
Dieses Ausgabensystem wird schrittweise eingestellt. Sie können vorhandene traditionelle Ausgaben anzeigen, bearbeiten und löschen, können aber keine neuen Ausgaben mit dieser Methode erstellen. Bitte verwenden Sie [KI-Ausgaben](../ai-expenses/overview) für alle neuen Ausgabenverarbeitungen.
:::

Traditionelle Ausgaben ist das ursprüngliche Ausgabenverfolgungssystem von Fiskl. Während dieses System für die Verwaltung historischer Aufzeichnungen weiterhin verfügbar bleibt, sollten alle neuen Ausgaben über KI-Ausgaben verarbeitet werden, um eine automatisierte Datenextraktion und Abstimmung zu ermöglichen.

## Was Sie tun können

**Vorhandene Ausgaben anzeigen:**
- Greifen Sie auf alle Ausgaben zu, die vor KI-Ausgaben erstellt wurden
- Überprüfen Sie historische Ausgabendatensätze
- Exportieren Sie Daten für Berichte

**Ausgaben bearbeiten:**
- Aktualisieren Sie Ausgabendetails
- Ändern Sie Kategorien und Beträge
- Ändern Sie Daten und Beschreibungen
- Fügen Sie Anhänge hinzu oder aktualisieren Sie diese

**Ausgaben löschen:**
- Entfernen Sie fehlerhafte oder doppelte Ausgaben
- Bereinigen Sie historische Aufzeichnungen

**Was Sie nicht tun können:**
- Erstellen Sie keine neuen Ausgaben in diesem System
- Verwenden Sie keine mobilen OCR-Funktionen für neue Belege
- Greifen Sie nicht auf automatisierte Abstimmungsfunktionen zu

## Migration zu KI-Ausgaben

Wir empfehlen, alle neuen Ausgaben über KI-Ausgaben zu verarbeiten:

**Vorteile des Wechsels:**
- Automatische Datenextraktion aus Belegen
- Keine manuelle Eingabe erforderlich
- Automatische Abstimmung mit Banktransaktionen
- Schnellere Verarbeitungszeit
- Bessere Genauigkeit durch OCR

**Für vorhandene traditionelle Ausgaben:**
- Behalten Sie diese im System für historische Aufzeichnungen
- Keine Migration erforderlich, es sei denn, Sie möchten dies
- Berichte enthalten sowohl traditionelle als auch KI-Ausgaben
- Beide Systeme sind in Ihre Buchhaltung integriert

## Zugriff auf traditionelle Ausgaben

Traditionelle Ausgaben werden in der Navigation angezeigt, wenn Sie historische Ausgaben haben:

1. **Erweitern Sie das Menü Ausgaben**

   Wählen Sie den Pfeil neben **Ausgaben** in der linken Seitenleiste.

2. **Wählen Sie Traditionelle Ausgaben**

   Wählen Sie **Traditionelle Ausgaben**, um Ihre Legacy-Ausgabendatensätze anzuzeigen.

## Grundlegendes zu traditionellen Ausgabentypen

Das traditionelle System hatte zwei Arten von Ausgaben:

### Eigenständige Ausgaben

Ausgaben, die unabhängig von Buchungstransaktionen erfasst werden:
- Erstellt über das Web-Dashboard oder die mobile App
- Beeinflussen die Buchhaltung erst nach manueller Abstimmung
- Können an Rechnungen angehängt werden zur Fakturierung
- Erfordern manuelle Dateneingabe

### Direkte Buchhaltungsausgaben

Ausgaben, die direkt in Konten erfasst werden:
- Sofort in der Buchhaltung berücksichtigt
- Erstellt bei der Kategorisierung von Banktransaktionen
- Können zur Fakturierung Kunden zugeordnet werden
- Keine separate Abstimmung erforderlich

## Komponenten traditioneller Ausgaben

Traditionelle Ausgaben enthalten normalerweise:

**Erforderliche Felder:**
- Betrag
- Kategorie
- Datum

**Optionale Felder:**
- Beschreibung
- Bilder (Belege)
- Kunde (für in Rechnung zu stellende Ausgaben)
- Lieferant
- Zahlungsart
- Notizen

## Verwaltung traditioneller Ausgaben

### Ausgabendetails anzeigen

So zeigen Sie eine traditionelle Ausgabe an:

1. Wählen Sie **Traditionelle Ausgaben** aus der Seitenleiste
2. Wählen Sie die Ausgabe aus der Liste
3. Zeigen Sie alle Ausgabendetails und Anhänge an

### Bearbeiten von Ausgaben

So ändern Sie eine vorhandene Ausgabe:

1. Wählen Sie die Ausgabe aus, die Sie bearbeiten möchten
2. Wählen Sie **Bearbeiten**
3. Aktualisieren Sie die erforderlichen Felder
4. Wählen Sie **Speichern**

### Löschen von Ausgaben

So entfernen Sie eine Ausgabe:

1. Wählen Sie die zu löschende Ausgabe
2. Wählen Sie **Löschen**
3. Bestätigen Sie das Löschen

:::warning
Das Löschen einer Ausgabe ist permanent und kann nicht rückgängig gemacht werden. Stellen Sie sicher, dass Sie Sicherungen wichtiger Aufzeichnungen erstellt haben, bevor Sie löschen.
:::

## In Rechnung zu stellende Ausgaben im traditionellen System

Traditionelle Ausgaben können weiterhin als in Rechnung zu stellend markiert werden:

**So machen Sie eine Ausgabe in Rechnung zu stellend:**
1. Bearbeiten Sie die Ausgabe
2. Weisen Sie einen Kunden zu
3. Speichern Sie die Ausgabe

**So fügen Sie eine Rechnung hinzu:**
1. Erstellen oder bearbeiten Sie eine Rechnung
2. Fügen Sie in Rechnung zu stellende Ausgaben vom Kunden hinzu
3. Ausgaben werden als Positionen angezeigt

Nach dem Hinzufügen zu einer Rechnung kann die Ausgabe nicht auf anderen Rechnungen verwendet werden.

## Abstimmung traditioneller eigenständiger Ausgaben

Eigenständige traditionelle Ausgaben erfordern manuelle Abstimmung:

1. **Finden Sie die Banktransaktion**

   Suchen Sie die entsprechende Transaktion in Ihrer Bank-, Kreditkarten- oder Kassenkonto auf.

2. **Vergleichen Sie mit Ausgabe**

   Verwenden Sie die Vergleichsfunktion, um die Ausgabe mit der Transaktion zu verknüpfen.

3. **Vergleich bestätigen**

   Überprüfen Sie die Details und bestätigen Sie die Abstimmung.

Dieser Prozess stellt sicher, dass die Ausgabe korrekt in Ihren Finanzberichten angezeigt wird.

## Berichte und traditionelle Ausgaben

Traditionelle Ausgaben werden in allen relevanten Finanzberichten angezeigt:

- Ausgabenberichte nach Kategorie
- Lieferantenausgabenanalyse
- In Rechnung zu stellende Kundenausgabenberichte
- Gewinn- und Verlustrechnungen
- Steuerberichte

Berichte enthalten automatisch sowohl traditionelle als auch KI-Ausgaben und bieten vollständige finanzielle Transparenz.

## Best Practices für Legacy-Ausgaben

**Verwalten Sie historische Aufzeichnungen:**
- Behalten Sie traditionelle Ausgaben für Audit-Trails
- Löschen Sie nur wenn absolut notwendig
- Exportieren Sie Daten vor größeren Bereinigungen

**Verwenden Sie KI-Ausgaben für zukünftige Ausgaben:**
- Hören Sie auf, traditionelle Ausgaben zu erstellen
- Schalten Sie alle neue Ausgabenverarbeitung auf KI-Ausgaben um
- Schulen Sie Ihre Mitglieder im neuen System

**Gleichen Sie ausstehende Ausgaben ab:**
- Schließen Sie alle ausstehenden traditionellen Ausgabenabstimmungen ab
- Gleichen Sie nicht abgestimmte Ausgaben mit Banktransaktionen ab
- Beenden Sie das traditionelle System ordnungsgemäß

**Dokumentieren Sie Geschäftsprozesse:**
- Notieren Sie, warum bestimmte traditionelle Ausgaben existieren
- Behalten Sie Aufzeichnungen über verwendete Abstimmungsmethoden
- Führen Sie Dokumentation für Buchhaltungsüberprüfungen

## Übergangszeitplan

**Aktueller Status:**
- Traditionelle Ausgaben sind nur für Anzeige/Bearbeitung/Löschen
- Keine neue Ausgabenerstellung in diesem System
- KI-Ausgaben verarbeitet alle neuen Vorgänge

**Zukünftige Pläne:**
- Traditionelle Ausgaben bleiben auf unbestimmte Zeit zugänglich
- Historische Daten werden nicht automatisch migriert
- Sie können Legacy-Aufzeichnungen weiterhin nach Bedarf verwalten
