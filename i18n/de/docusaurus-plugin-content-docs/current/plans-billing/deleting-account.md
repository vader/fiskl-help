# Konto löschen

Diese Anleitung erklärt, wie Sie Ihr Fiskl-Konto dauerhaft löschen und hilft Ihnen, den vollständigen Datenlöschungsprozess zu verstehen.

## Konto-Löschung verstehen

Das Löschen Ihres Kontos entfernt alle Ihre Daten dauerhaft aus Fiskl. Diese Aktion unterscheidet sich von der Kündigung Ihres Abonnements, das Ihre Daten intakt hält.

**Was wird gelöscht:**
- Alle Finanzunterlagen und Transaktionen
- Rechnungen, Angebote und Kostenvoranschläge
- Kunden- und Lieferanteninformationen
- Bankverbindungen und Transaktionsverlauf
- Berichte und gespeicherte Daten
- Benutzereinstellungen und Voreinstellungen
- Unternehmensinformationen und Branding

:::warning
Das Löschen von Konten ist dauerhaft und kann nicht rückgängig gemacht werden. Alle Daten werden dauerhaft gelöscht und können nicht wiederhergestellt werden.
:::

## Vor dem Löschen Ihres Kontos

Führen Sie diese Schritte vor dem Löschen durch:

**Exportieren Sie Ihre Daten:**
1. Laden Sie wichtige Rechnungen und Berichte herunter
2. Exportieren Sie Ihren Transaktionsverlauf
3. Speichern Sie alle benötigten Finanzunterlagen
4. Sichern Sie Kontaktinformationen von Kunden und Lieferanten

**Offene Posten begleichen:**
1. Zahlung für ausstehende Rechnungen einfordern
2. Ausstehende Lieferantenrechnungen bezahlen
3. Laufende Projekte abschließen
4. Kunden über die Kontoschließung benachrichtigen

**Alternativen überprüfen:**
- Erwägen Sie, Ihr Abonnement zu kündigen, wenn Sie möglicherweise zurückkehren
- Downgrade auf den kostenlosen Plan, um Zugriff ohne Gebühren zu behalten
- Exportieren Sie Daten regelmäßig, auch wenn Sie Ihr Konto behalten

## Wie Sie Ihr Konto löschen

Stellen Sie vorher sicher, dass Sie alle Daten exportiert haben, die Sie behalten möchten.

**Schritte:**

1. **Öffnen Sie Benutzereinstellungen**

   Wählen Sie Ihr Profilsymbol oben rechts und wählen Sie **Benutzereinstellungen**.

2. **Gehen Sie zu Kontoeinstellungen**

   Wählen Sie die Registerkarte **Kontoeinstellungen**.

3. **Zugriff auf den sensiblen Bereich**

   Scrollen Sie nach unten zum Abschnitt für sensible Operationen.

4. **Wählen Sie Konto löschen**

   Wählen Sie die Schaltfläche **Konto löschen**.

5. **Bestätigen Sie das Löschen**

   Lesen Sie die Warnmeldung sorgfältig und bestätigen Sie, dass Sie mit der permanenten Löschung fortfahren möchten.

Ihr Konto und alle zugehörigen Daten werden nun dauerhaft gelöscht. Sie werden sofort abgemeldet.

## Was bei der Löschung passiert

Wenn Sie Ihr Konto löschen, verarbeitet Fiskl diese Aktionen:

**Unmittelbare Auswirkungen:**
1. **Abmeldung**: Sie werden sofort von allen Geräten abgemeldet
2. **Bankverbindung trennen**: Alle Banking-Integrationen werden getrennt
3. **Zahlungsintegration entfernen**: Zahlungsanbieterverbindungen werden beendet
4. **Zugriff widerrufen**: Sie können sich nicht mehr bei Ihrem Konto anmelden

**Datenlöschung:**
1. **Finanzdaten**: Alle Transaktionen, Rechnungen und Berichte werden gelöscht
2. **Geschäftsdaten**: Kunden, Lieferanten und Produkte werden entfernt
3. **Persönliche Daten**: Ihre Profilinformationen und Unternehmensdaten werden gelöscht
4. **Sicherungen**: Daten werden aus allen Sicherungssystemen entfernt

**Dauerhafte Schließung:**
- Ihre E-Mail-Adresse wird für neue Registrierungen verfügbar
- Ihre Unternehmensdaten können von niemandem zugegriffen werden
- Es gibt keine Wiederherstellungsoptionen nach dem Löschen

## Konto-Löschung vs. Abonnementkündigung

Wählen Sie die richtige Option für Ihre Situation:

| Funktion | Konto löschen | Abonnement kündigen |
|---------|---------------|-------------------|
| **Daten** | Dauerhaft gelöscht | Bleiben erhalten |
| **Zugriff** | Vollständig entfernt | Kostenloser Plan-Zugriff |
| **Rückgängig machbar** | Nein | Ja (kann erneut abonnieren) |
| **Banking** | Getrennt | Nach Tagen getrennt |
| **Rechnungen** | Gelöscht | Erhalten |
| **Beste Option für** | Dauerhafte Schließung | Temporäre Unterbrechung |

:::info
Wenn Sie sich nicht sicher sind, ob Sie Ihre Daten in Zukunft benötigen, kündigen Sie Ihr Abonnement, statt Ihr Konto zu löschen. Sie können es später immer noch löschen.
:::

## Wann Sie Ihr Konto löschen sollten

Erwägen Sie die Kontolöschung, wenn:

**Geschäftsschließung:**
- Sie schließen Ihr Unternehmen dauerhaft
- Sie arbeiten nicht mehr als Freiberufler oder Selbstständiger
- Ihr Unternehmen wurde übernommen oder fusioniert

**Plattformwechsel:**
- Sie haben alle Daten in ein anderes System migriert
- Sie sind sicher, dass Sie nicht zu Fiskl zurückkehren
- Sie haben alle ausstehenden Arbeiten abgeschlossen

**Datenschutzbedenken:**
- Sie möchten die vollständige Datenlöschung aus unseren Systemen
- Sie müssen Daten aus Compliance-Gründen löschen
- Sie möchten keine Daten mehr gespeichert haben

## Alternativen zur Kontolöschung

Erwägen Sie vor dem Löschen diese Optionen:

**Abonnement kündigen:**
- Behalten Sie Ihre Daten und stoppen Sie die Gebühren
- Behalten Sie Zugriff auf den kostenlosen Plan
- Einfache Möglichkeit, erneut zu abonnieren, wenn Sie zurückkehren
- Weitere Informationen in [Abonnement kündigen](/plans-billing/canceling-subscription)

**Downgrade auf kostenlos:**
- Zugriff auf grundlegende Funktionen kostenlos
- Ihre Daten bleiben erhalten
- Keine Abrechnung oder Zahlung erforderlich
- Siehe [Wählen Sie Ihren Fiskl-Plan](/plans-billing/selecting-plans)

**Exportieren und pausieren:**
- Laden Sie alle Ihre Daten herunter
- Kündigen Sie Ihr Abonnement
- Behalten Sie die Option, mit einem neuen Start zurückzukehren

## Kontolöschung kann nicht rückgängig gemacht werden

Nachdem Sie Ihr Konto gelöscht haben:

- **Keine Wiederherstellung**: Daten können unter keinen Umständen wiederhergestellt werden
- **Kein Backup-Zugriff**: Wir können gelöschte Informationen nicht abrufen
- **Nur Neuanfang**: Sie können ein neues Konto mit derselben E-Mail erstellen, aber es wird völlig leer sein
- **Support kann nicht helfen**: Auch der Fiskl-Support kann gelöschte Konten nicht wiederherstellen

Wenn Sie Zweifel haben, wählen Sie Kündigung statt Löschung.

## Erneute Registrierung nach dem Löschen

Wenn Sie Ihr Konto löschen und später Fiskl wieder nutzen möchten:

1. **Erstellen Sie ein neues Konto**: Registrieren Sie sich mit derselben oder einer anderen E-Mail
2. **Neuanfang**: Ihr neues Konto hat keine historischen Daten
3. **Von Grund auf einrichten**: Konfigurieren Sie Einstellungen, verbinden Sie Banking und fügen Sie Kunden erneut hinzu
4. **Keine Datenübertragung**: Zuvor gelöschte Daten können nicht wiederhergestellt werden
