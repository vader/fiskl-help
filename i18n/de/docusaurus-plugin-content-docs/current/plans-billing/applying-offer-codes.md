# Angebotscodes anwenden

Diese Anleitung erklärt, wie Sie Angebotscodes auf Ihr Fiskl-Abonnement anwenden und wie Sie mit Aktions- und Partnerarabätten maximale Ersparnisse erzielen.

## Angebotscodes verstehen

Fiskl bietet Einführungsangebote bei der Registrierung und gelegentlich spezielle Partnercodes mit einzigartigen Bedingungen. Diese Codes bieten ermäßigte Sätze für bestimmte Zeiträume oder spezielle Bedingungen, die von Partnern verwaltet werden.

## Angebotscodes anwenden

Sie können Angebotscodes auf drei Arten anwenden:

### Methode 1: Während der Registrierung

1. **Gehen Sie zur Registrierungsseite**

   Besuchen Sie die [Fiskl-Registrierungsseite](https://my.fiskl.com/registration).

2. **Wählen Sie den Angebotscodlink**

   Wählen Sie den Link **Haben Sie einen Angebotscode?** in der oberen rechten Ecke.

3. **Geben Sie Ihren Code ein**

   Geben Sie Ihren Angebotscode ein oder fügen Sie ihn ein und wählen Sie **Anwenden**.

4. **Registrierung abschließen**

   Setzen Sie Ihre Registrierung fort. Der Rabatt wird automatisch angewendet.

### Methode 2: Verwenden einer speziellen URL

Einige Partner stellen direkte Registrierungslinks mit eingebetteten Angebotscodes zur Verfügung:

```
https://my.fiskl.com/registration?code=your-offer
```

Wenn Sie diese URLs verwenden, wird das Angebot automatisch angewendet, ohne dass eine manuelle Eingabe erforderlich ist.

### Methode 3: In den Benutzereinstellungen

Wenn Sie bereits ein Konto haben, können Sie bestimmte Angebotscodes über Einstellungen anwenden:

1. **Benutzereinstellungen öffnen**

   Wählen Sie Ihr Profilsymbol und dann **Benutzereinstellungen**.

2. **Gehen Sie zu Kontoeinstellungen**

   Wählen Sie die Registerkarte **Kontoeinstellungen**.

3. **Geben Sie den Angebotscode ein**

   Geben Sie Ihren Code im Feld **Angebots- oder Partnercode** ein.

4. **Wenden Sie den Code an**

   Wählen Sie **Anwenden**, um den Rabatt zu aktivieren.

:::tip
Die meisten Angebotscodes funktionieren am besten, wenn sie bei der ersten Registrierung angewendet werden. Einige Codes sind möglicherweise nicht für bestehende Konten verfügbar.
:::

## Wichtige Regeln für Angebote

Das Verständnis dieser Einschränkungen hilft Ihnen, verfügbare Rabatte optimal zu nutzen:

**Angebotskombination ist nicht zulässig:**
- Sie können mehrere Angebotscodes nicht kombinieren
- Wenn Sie bei der Registrierung ein Angebot erhalten haben, können Sie später kein anderes Angebot anwenden
- Nur eine Rabattaktion kann gleichzeitig aktiv sein

**Angebote haben Ablaufdaten:**
- Alle Angebote laufen nach ihrer festgelegten Dauer automatisch ab
- Sie werden benachrichtigt, bevor ein Angebot endet
- Nach dem Ablauf wird Ihnen der Standardsatz für Ihren Plan berechnet

**Regionale und planabhängige Einschränkungen:**
- Einige Angebote gelten nur für bestimmte Regionen oder Länder
- Bestimmte Codes funktionieren nur mit bestimmten Plantarife
- Partnercodes können einzigartige Bedingungen haben

**Rechnungsverwaltung:**
- Einige Partnerangebote beinhalten spezielle Rechnungsregelungen
- Die von Partnern verwaltete Abrechnung kann unterschiedliche Zahlungspläne haben
- Überprüfen Sie die Bedingungen sorgfältig für partnerspezifische Codes

## Standard- und Partnerangebote

Fiskl bietet zwei Arten von Aktionscodes:

**Standard-Einführungsangebote:**
- Für alle neuen Benutzer während der Registrierung verfügbar
- Bieten normalerweise das beste Gesamtwert-Preis-Verhältnis
- Direkt von Fiskl verwaltet
- Standard-Geschäftsbedingungen gelten

**Partnercodes:**
- Bereitgestellt durch spezifische Partnerschaften oder Zugehörigkeiten
- Können einzigartige Vorteile oder erweiterte Bedingungen bieten
- Manchmal mit partnergemanagter Abrechnung
- Wird für spezielle Fälle oder zielgerichtete Aktionen verwendet

:::info
Die Standard-Einführungsangebote von Fiskl sind normalerweise die besten verfügbaren. Partnercodes dienen speziellen Fällen und können andere Bedingungen haben.
:::

## Was geschieht, wenn ein Angebot abläuft

Wenn Ihr Angebotscode sein Ablaufdatum erreicht:

1. **Automatischer Übergang**: Ihr Abonnement wird zum Standardsatz für Ihren aktuellen Plan fortgesetzt
2. **Vorabbenachrichtigung**: Fiskl benachrichtigt Sie, bevor das Angebot abläuft
3. **Keine Serviceunterbrechung**: Ihre Funktionen und der Zugriff bleiben unverändert
4. **Ratenbereinigung**: Ihre nächste Rechnung spiegelt die neue Standardpreisgestaltung wider

Sie können zu einem niedrigeren Plan wechseln, bevor das Angebot abläuft, wenn die neue Rate Ihr Budget übersteigt.
