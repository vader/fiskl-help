This section explains how to configure Fiskl settings to match your business requirements, from company branding to tax configuration and invoice templates.

## Why Configure Settings?

Properly configured settings ensure accurate financial records, professional-looking invoices, and compliant tax reporting. Taking time to set up your account correctly saves time and prevents errors throughout your Fiskl usage.

**Key benefits:**
- Professional branded invoices and quotes
- Accurate tax calculations and reporting
- Compliant financial documentation
- Personalized user experience
- Efficient workflow automation
- Multi-currency support

## Settings Categories

## Settings Hierarchy

Understanding which settings override others helps you configure Fiskl effectively.

### Global Settings (Company Level)

Apply to all transactions unless overridden:
- Company information
- Base currency
- Default tax rates
- General invoice settings
- Accounting method

### Template/Brand Settings

Override company settings for specific invoices:
- Brand-specific logo
- Custom contact information
- Template-specific styling
- Brand colors and fonts
- Alternative email addresses

### Transaction Settings

Override defaults for individual transactions:
- Client-specific currency
- Custom payment terms
- Special tax treatment
- One-off discounts
- Transaction-specific notes

### User Settings

Apply only to individual user accounts:
- Personal information
- Notification preferences
- Language settings
- Personal billing rates
- Security settings

## Common Settings Workflows

### Initial Account Setup

Complete these settings in priority order:

**Priority 1: Essential Company Information (5 minutes)**
1. Go to Company Settings
2. Enter company name and address
3. Add tax ID/registration number
4. Upload company logo
5. Set time zone

**Priority 2: Tax Configuration (10 minutes)**
1. Go to Tax Management
2. Add your tax rates (VAT/GST/Sales Tax)
3. Set default tax treatment
4. Configure tax-exempt rules if needed
5. Enter tax authority details

**Priority 3: Invoice Defaults (10 minutes)**
1. Go to Invoice & Quote Settings
2. Set default payment terms
3. Configure invoice numbering
4. Add payment method options
5. Set default footer text

**Priority 4: Template Design (15 minutes)**
1. Go to Invoice Templates & Brands
2. Customize default template colors
3. Adjust logo placement
4. Select font preferences
5. Preview and test template

**Total setup time: ~40 minutes**

### Multi-Currency Setup

For international business operations:

**Step 1: Currency Activation**
1. Go to Currency Management
2. Activate all currencies you need
3. Select exchange rate source
4. Set base accounting currency preference

**Step 2: Client Configuration**
1. Go to Clients section
2. Set preferred currency per client
3. Configure currency-specific terms
4. Test invoice generation

**Step 3: Reporting Setup**
1. Select currency for reports
2. Configure exchange rate display
3. Set up currency gain/loss tracking
4. Test multi-currency reports

### Multi-Brand Setup

For businesses with multiple service lines:

**Step 1: Default Template**
1. Configure primary brand template
2. Set main company details
3. Design primary template style
4. Test with sample invoice

**Step 2: Additional Brands**
1. Create new brand template
2. Upload brand-specific logo
3. Customize colors and styling
4. Set alternative contact details
5. Configure brand-specific email templates

**Step 3: Client Assignment**
1. Assign clients to appropriate brands
2. Set default template per client
3. Test invoice generation per brand
4. Verify brand consistency

### Team Collaboration Setup

For businesses with multiple users:

**Step 1: User Roles** (via Team Management)
1. Invite team members
2. Assign appropriate roles
3. Set access permissions
4. Configure workflow assignments

**Step 2: Personal Settings** (each user)
1. Complete profile information
2. Set notification preferences
3. Configure personal billing rates
4. Set language preferences

**Step 3: Workflow Standards**
1. Document settings standards
2. Train team on settings
3. Establish approval workflows
4. Monitor settings consistency

## Troubleshooting Common Issues

### Cannot Change Base Currency

**Cause:** Base currency locks after first transaction

**Solution:**
1. Base currency cannot be changed after transactions exist
2. Contact support if absolutely necessary
3. Consider creating new account for different currency
4. Use multi-currency features instead

### Tax Calculations Incorrect

**Cause:** Tax rate or settings misconfigured

**Solution:**
1. Review Tax Management for accuracy
2. Verify tax rate percentages
3. Check compound tax settings
4. Test with sample invoice
5. Update if rates changed

### Invoice Template Not Applying

**Cause:** Client-specific template override or brand assignment

**Solution:**
1. Check client's default template setting
2. Verify brand assignment
3. Review template selection on invoice
4. Clear template cache if needed
5. Re-save template preferences

### Notifications Not Received

**Cause:** Notification preferences or email issues

**Solution:**
1. Check Profile Settings notifications
2. Verify email address is correct
3. Check spam folder
4. Test notification settings
5. Update email preferences

### Exchange Rate Outdated

**Cause:** Manual override or delayed update

**Solution:**
1. Go to Currency Management
2. Check exchange rate source
3. Clear manual overrides if needed
4. Force exchange rate refresh
5. Verify rate accuracy
