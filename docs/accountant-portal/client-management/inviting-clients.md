This guide explains how to generate invitation links and invite clients to join your practice in the Accountant Portal.

## How Client Invitations Work

The Accountant Portal provides unique invitation links that connect clients to your practice during their account creation.

**Key benefits:**
- One reusable link per branch and billing model
- Clients automatically connect during signup
- No manual connection process needed
- Track which link clients used
- Organized by branch structure

## Invitation Link Types

Generate different invitation links based on your billing model preference for each client relationship.

### Bill Us Invitation Links

Generate links for clients you will bill through your practice subscription.

**How it works:**
1. Generate Bill Us invitation link for a branch
2. Share link with specific client
3. Client creates account using your link
4. Client automatically connects to your practice
5. You pay for client's subscription

**Best for:**
- Direct client invitations via email
- Clients who want full-service packages
- Small clients needing complete support
- Clients requiring minimal system access

**Learn more:** [Bill Us Model](/accountant-portal/billing-models/bill-us-model)

### Client Pays Invitation Links

Generate links for clients who will pay their own subscriptions.

**How it works:**
1. Generate Client Pays invitation link for a branch
2. Share link on website, email signature, or marketing
3. Client creates account using your link
4. Client completes setup and sends you invitation
5. You accept or reject invitation in portal
6. Client pays their own subscription

**Best for:**
- Website or public marketing materials
- Clients wanting account control
- Larger clients with internal teams
- Practices wanting flexible relationships

**Learn more:** [Client Pays Model](/accountant-portal/billing-models/client-pays-model)

## Generating Invitation Links

Create invitation links for each branch and billing model combination.

### Generate Bill Us Link

**To create a Bill Us invitation link:**

1. Go to **Clients** in portal navigation
2. Select **Invite Client**
3. Select **Bill Us Model**
4. Select target **Branch** where client will be managed
5. Select **Generate Link**
6. Copy the generated invitation link

**Generated link format:**
```
https://my.fiskl.com/signup?accountant=[your-code]&branch=[branch-id]&model=bill-us
```

**Link characteristics:**
- Unique to your practice and selected branch
- Reusable for multiple clients
- Automatically applies Bill Us billing
- Identifies your practice during client signup
- Never expires unless regenerated

### Generate Client Pays Link

**To create a Client Pays invitation link:**

1. Go to **Clients** in portal navigation
2. Select **Invite Client**
3. Select **Client Pays Model**
4. Select target **Branch** where invitations will be received
5. Select **Generate Link**
6. Copy the generated invitation link

**Generated link format:**
```
https://my.fiskl.com/signup?accountant=[your-code]&branch=[branch-id]&model=client-pays
```

**Link characteristics:**
- Unique to your practice and selected branch
- Reusable across marketing channels
- Automatically applies Client Pays billing
- Client must send you invitation after signup
- Never expires unless regenerated

## Sharing Invitation Links

Use different sharing methods depending on the billing model and client relationship.

### Sharing Bill Us Links

Direct, personal sharing works best for Bill Us invitations.

**Email invitation:**
```
Subject: Invitation to Connect Your Fiskl Account

Hi [Client Name],

I'm excited to begin working with you on your business finances.

Please create your Fiskl account using this link:
[Your Bill Us Invitation Link]

This will automatically connect your account to my practice, and I'll handle all the setup and billing for you.

Once you've created your account, I'll begin configuring everything we discussed.

Let me know if you have any questions!

Best regards,
[Your Name]
[Your Practice Name]
```

**Messaging platforms:**
- Send link directly via WhatsApp, Slack, or Teams
- Include brief explanation of what happens next
- Offer to answer questions during signup
- Follow up after client creates account

**Best practices:**
- Personalize each invitation
- Explain what client needs to do
- Clarify that you'll handle billing
- Set expectations for next steps
- Provide contact method for questions

### Sharing Client Pays Links

Broader distribution works well for Client Pays invitations.

**Website integration:**
- Add link to "Work with Us" or "Services" page
- Include in accountant directory listings
- Create dedicated landing page
- Add to contact forms
- Include in service packages

**Email signature:**
```
[Your Name]
[Your Title] | [Your Practice Name]
[Phone] | [Email]

New Clients: Create your Fiskl account and connect with me
[Your Client Pays Invitation Link]
```

**Marketing materials:**
- Include in brochures and flyers
- Add to proposals and quotes
- Include in onboarding documents
- Share in networking events
- Add to social media profiles

**Best practices:**
- Label link clearly ("Connect with Our Practice")
- Explain benefits of using the link
- Set expectations (client sends invitation)
- Provide alternative contact method
- Track which channels perform best

## Invitation Link Security

Invitation links are safe to share but follow these best practices.

**Security considerations:**
- Links connect clients to your practice only
- Links cannot access existing accounts
- Links work only during new account creation
- You control final acceptance (Client Pays model)
- You can regenerate links anytime

**Regenerating links:**

If you want to invalidate existing links:
1. Go to **Clients** > **Invite Client**
2. Select branch and model
3. Select **Regenerate Link**
4. Confirm action
5. Old links stop working immediately
6. Share new link going forward

**When to regenerate:**
- Link accidentally shared publicly
- Team member with access leaves practice
- Restructuring branch organization
- Changing invitation strategy
- Security concern arises

## Monitoring Invitation Activity

Track which clients use your invitation links and when.

**Activity metrics:**
- Total signups per link
- Signups by date range
- Conversion from signup to connection
- Pending invitations (Client Pays)
- Active clients per branch

**Tracking new clients:**

1. Go to **Clients** in portal
2. Filter by **Connection Date**
3. Select date range
4. View recent connections
5. Check which branch received client

**Pending invitations (Client Pays):**
- Badge in sidebar shows pending count
- Select **Client Invitations** to review
- Accept or reject each invitation
- Monitor time from signup to invitation

**Learn more:** [Accepting Client Invitations](/accountant-portal/client-management/accepting-client-invitations)

## Client Signup Experience

Understand what happens when clients use your invitation links.

### Bill Us Signup Flow

**Client experience:**
1. Selects your invitation link
2. Sees "Setting up account with [Your Practice Name]"
3. Enters their company information
4. Creates login credentials
5. Completes basic setup wizard
6. Account automatically connects to your practice
7. You receive notification of new client

**Your experience:**
1. Client appears in your Clients list immediately
2. Client assigned to branch specified in link
3. Billing begins automatically in your subscription
4. You can access client account immediately
5. Begin configuration and onboarding

### Client Pays Signup Flow

**Client experience:**
1. Selects your invitation link
2. Sees "Connect with [Your Practice Name]"
3. Enters their company information
4. Creates login credentials
5. Completes full setup wizard independently
6. Sends invitation to connect with you
7. Waits for your acceptance

**Your experience:**
1. Notification of pending invitation arrives
2. Badge appears in sidebar navigation
3. Review invitation details and client message
4. Accept or reject invitation
5. If accepted, client appears in Clients list
6. Begin working in client account

## Invitation Best Practices

**For Bill Us invitations:**

## Troubleshooting

### Client Cannot Access Invitation Link

**Cause:** Link formatting issue or browser problem

**Solution:**
1. Verify link copied completely
2. Remove extra spaces or line breaks
3. Try different browser
4. Send link as plain text (not formatted)
5. Regenerate link if corrupted

### Client Connected to Wrong Branch

**Cause:** Used invitation link for different branch

**Solution:**
1. Go to client settings in portal
2. Select **Change Branch**
3. Select correct branch
4. Confirm transfer
5. Notify team of change

### Client Used Bill Us Link But Wants Client Pays

**Cause:** Wrong link shared or selected

**Solution:**
1. Cannot change billing model after connection
2. Disconnect client from practice
3. Share correct Client Pays link
4. Client creates new account with correct link
5. Or continue with Bill Us if client agrees

### Invitation Link Not Working

**Cause:** Link expired or regenerated

**Solution:**
1. Generate new invitation link
2. Share new link with client
3. Verify link works before sharing
4. Update any saved links
5. Notify team of new link

### No Notification After Client Signup (Bill Us)

**Cause:** Email notification settings or delay

**Solution:**
1. Check Clients list directly in portal
2. Verify notification settings enabled
3. Check spam folder
4. Wait 15 minutes for processing
5. Contact support if client missing

### Client Never Sent Invitation (Client Pays)

**Cause:** Client completed signup but didn't send invitation

**Solution:**
1. Cannot be resolved from your side
2. Contact client directly
3. Ask client to log in and send invitation
4. Client finds invitation option in their settings
5. Or share new link for fresh signup
